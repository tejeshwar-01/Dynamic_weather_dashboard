# 🌦️ Dynamic Weather App

A visually stunning **real-time weather app** that blends **aesthetic design** with **dynamic weather effects**.  
Powered by the **OpenWeather API**, this project transforms raw weather data into an **immersive experience** — where rain pours, snow drifts, thunder flashes, and the sun or moon rises depending on the time of day.  

---

## ✨ Features
- 🌍 **Global Search** → Get live weather data for any city worldwide.  
- 🎨 **Dynamic Backgrounds** → Animated gradients that adapt to the weather & time.  
- ☀️🌙 **Sun & Moon Simulation** → Auto-switches between day/night modes.  
- 🌧️❄️⚡ **Interactive Weather Effects** → Real raindrops, snowflakes, moving clouds, and lightning flashes.  
- 📱 **Responsive Design** → Works seamlessly on desktop & mobile.  
- 🚀 **Lightweight & Fast** → Pure HTML, CSS & JavaScript.  

---

## 🛠️ Tech Stack
- **HTML5** → Structure  
- **CSS3 (Glassmorphism + Animations)** → Styling & effects  
- **Vanilla JavaScript (ES6)** → API fetch + dynamic rendering  
- **OpenWeather API** → Real-time weather data

## ⚡ How It Works
1. Enter a city name in the search bar.  
2. Fetches weather data from **OpenWeather API**.  
3. Displays temperature, humidity & conditions.  
4. Triggers **real-time animations** (rain, snow, thunder, sun, moon).
